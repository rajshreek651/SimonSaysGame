# SimonSaysGame
The Simon Says Game is built using the concepts of HTML, CSS and JavaScript. It is built to memorize the color sequence order and score the highest to make the next highest record.

## Understanding the exexution of Game

1. When enter key is pressed from the keyboard, an eventListener set for it is tracked

2. The Level ups from 0 to 1, &, one of the 4 buttons on the screen, flashes .

3. gameSeq[] will contain the sequence of colors generated by the game, &, userSeq[] will contain the sequence of colors generated by the user.
    So, we check the sequence of colors as pressed by the users is aligned with game's color sequence. 
    
4. If at any point userSeq[i] doesn't match with gameSeq[i], the Game gets OVER.
    If the user enter the correct sequence of color: the Level Ups, &, a color button on the screen flashes
